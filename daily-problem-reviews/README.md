# Daily problem reviews

Owned by Prestel Coder for review-only daily passes. Application source stays untouched unless a separate implement job is authorized.

## Files

- One dated file per review day: `YYYY-MM-DD.md` (America/Sao_Paulo).
- Status vocabulary: **OPEN** / **PARTIAL** / **OK**.
- Carry unsolved items forward into the next dated file. Mark solved items **OK** in the earlier file when re-verified.

## Finding fields

Stable ID, area, problem, evidence/cause, status, next action. Prefer `PRESTEL-YYYYMMDD-NNN` IDs for review findings; cite Linear `GEN-N` when the mismatch is tracker vs tree.

## Rules

- No application source edits from a review pass.
- No `git push`, force-push, commit, amend, or stash on the review pass.
- Do not invent Linear IDs; discover them from the connected Linear account.
- Logs may change; the repository is the technical source of truth.
